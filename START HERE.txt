TITAN SPACE STUDIO — PHOTO TO BLENDER

Open the existing website:
https://titan-space-studio.onrender.com/

Sign in as titan with your site password. No local Python, Blender, paid
scene-generation account, or ZIP download is required to use the website.
The updated feature must be deployed and connected to a reconstruction worker.

1. Choose a clear garage or interior photo.
2. Click Create 3D walkthrough. Follow the actual processing stages.
3. Compare photo shows your reference beside the matched 3D source view.
   Blender preview shows the source-camera still generated by Blender.
4. Choose Walk through to explore with mouse/WASD or arrow keys.
   On touch screens, drag to look and hold the movement arrows.
5. Review confidence notes. Optional corrections can adjust room dimensions,
   camera alignment, wall corners and major object positions, then rebuild.
6. Saved spaces reopen completed projects. GLB, .blend, scene JSON and preview
   downloads are available after a successful reconstruction.

Reloading reconnects to the saved job. Cancel reconstruction requests that the
worker stop; merely closing the browser leaves the job running.

One photo cannot establish exact measurements, hidden areas or every object.
The worker builds actual meshes for supported room surfaces and major objects.
Unsupported photos must report a failure rather than a substituted sample room.

If the site says Reconstruction worker needed, see DEPLOY.md. The lightweight
website needs a separate configured Blender worker with model files and durable
storage. The old Windows ZIP packages contain the previous workflow and have
been retired.

Developers running this source checkout should read README.md first. Configure
SITE_PASSWORD, WORKER_URL and WORKER_TOKEN in the process environment, install
the pinned web dependencies, and build the frontend. The existing Windows and
Mac launcher scripts then run the loopback website proxy; they do not install
Blender or provision a worker. No paid provider API key is used.
