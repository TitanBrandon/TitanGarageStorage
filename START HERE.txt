TITAN SPACE STUDIO v0.2 — PHOTO TO WORLD

1. Install Python 3.12 from https://www.python.org/downloads/release/python-31210/
   On Windows, select "Add python.exe to PATH" in the installer.

2. Extract the entire ZIP to a folder on your computer. Do not run it inside the ZIP.

3. Windows: double-click "Start Windows.bat".
   Mac: double-click "Start Mac.command".
   If Mac does not open it, open Terminal in this folder and run:
     bash "Start Mac.command"

The first start installs dependencies. The launcher then asks for your World Labs
API key. Create an API account and key at https://platform.worldlabs.ai/ and add
credits there. These API credits may be separate from a consumer subscription.
The key is hidden while you type/paste it and is not saved to disk. You enter it
again on each launch. To skip the key and import a scene export, press Enter.

Your browser opens automatically when the app is ready. Keep the terminal window
open while using it. Press Ctrl+C in that window to stop the app.

Choose a photo, choose the generation quality, then click the generation button.
Generation sends your photo to World Labs and spends your API credits. It can
take several minutes. The app never automatically retries a paid submission.
You can also import an existing SPZ/PLY/SPLAT scene without an API key.

The new viewer displays real Gaussian-splat scene data. It does not show the old
cartoon showroom. One-photo world generation estimates hidden areas; it does not
produce a measured scan or guarantee exact cars, signs or room dimensions.

Publishing the Codex environment saves a development workspace. This download is
a way to run the app on your computer; it does not deploy a public website.
